# Green Impact — Uma Jornada Sustentável

Jogo educativo sobre sustentabilidade e Objetivos de Desenvolvimento Sustentável, com versões separadas para PC, Android e iOS/macOS.

## Pastas

- `Green_Impact_PC/` — cliente Pygame e compilação para Windows.
- `Green_Impact_Android/` — cliente Kivy e compilação com Buildozer.
- `Green_Impact_IOS/` — cliente Kivy para iOS/macOS.

## Atualização 0.4 — análise aplicada nas três versões

As três interfaces agora destacam o jogador da vez, separam respostas de ajudas, mostram saldo de carbono e custos, deixam **Parar** isolado no final da HUD e exibem uma tela própria de consequência. O servidor também expira perguntas automaticamente, mesmo quando o cliente não envia a mensagem de timeout.

Consulte `CORRECOES_ANALISE_TRES_VERSOES_V0.4.txt` para a lista completa.
