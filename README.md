# Green Impact - Uma Jornada Sustentável

Green Impact é um jogo educativo sobre sustentabilidade e Objetivos de Desenvolvimento Sustentável, com versões para PC, Android e macOS/iOS.

## Versões disponíveis

- `pc/` - versão para Windows/PC
- `android/` - versão Android com Kivy/Buildozer
- `macos-ios/` - versão preparada para macOS/iOS (em desenvolvimento)
